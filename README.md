# Статистический анализ продаж сети аптек

Проект по расчёту минимального недельного запаса для каждого товара на основе прогнозного интервала (95%) и формированию управленческих отчётов для оптимизации складских запасов.  
Выполнен в рамках итоговой работы по модулю «Математика и статистика».

---

## 🏥 Описание проекта

**Организация:** Крупная сеть аптек с распределительным складом и розничными точками.  

**Проблема:** Частые дефициты и излишки товаров из‑за отсутствия системного планирования – заказы делаются «на глаз» без учёта статистических закономерностей спроса.  

**Цель:** Определить минимальный недельный запас для каждого товара, который с вероятностью **95%** покрывает спрос, и предоставить управленческие отчёты для оптимизации запасов.

---

## 📊 Данные

Исходные данные находятся в файле **`data.csv`**:
- **45 128 записей** о розничных продажах за период с **1 мая по 9 июня 2022 года** (40 дней).
- Поля:
  - `dr_dat` – дата продажи
  - `dr_cdrugs` – уникальный код товара
  - `dr_kol` – количество проданных единиц
  - `dr_czak` – закупочная цена за единицу
  - `dr_croz` – розничная цена за единицу
  - `dr_ndrugs`, `dr_suppl`, `dr_prod` – название, поставщик, производитель

## 📐 Методология

### Этапы анализа (реализованы в `stat.py`)

1. **Подготовка данных** – загрузка, очистка, преобразование типов.
2. **Агрегация** – группировка продаж по товарам и дням, расчёт прибыли.
3. **Расчёт прогнозного интервала** для дневного и недельного запаса (95%) с использованием распределения Стьюдента.
4. **Коэффициент вариации (CV)** и группировка товаров по стабильности (A, B, C).
5. **ABC-анализ** по прибыли и по объёму продаж.
6. **Проверка статистических гипотез** (6 гипотез, включая независимость от дня недели и корреляцию цены со спросом).
7. **Визуализация** (графики сохраняются в `analysis_plots.png`).
8. **Экспорт результатов** в Excel-файл.

### Ключевые формулы

**Недельный запас (95%):**

\[
\text{WeekStock} = 7\bar{x} + t_{0.975, n-1} \cdot \sqrt{7} \cdot s \cdot \sqrt{1 + \frac{1}{n}}
\]

Если число дней с продажами \( n < 3 \), используется консервативная оценка:  
`WeekStock = ceil(1.5 × max_day × 7)`.
